# MotoFuel Planner - バイクツーリング給油計画＆ルート作成アプリ

バイクツーリングにおいて、タンク容量・燃費・安全率しきい値（デフォルト80%）を設定し、ガス欠になる前の最適な位置でガソリンスタンドを割り出してGoogleマップ用の経路データを作成するWebアプリケーションです。

---

## 🌟 主な特徴

1. **📁 保存したマイルート（Route Storage & History）**
   - 固定のプリセットを廃止し、**自分が作成したお気に入りルートをブラウザ内に保存・呼び出しできる機能**を搭載。
   - ルート作成後に「💾 現在のルートを保存」を押すだけで、名前を付けて保存可能。
   - 保存したルートをクリックすると、出発地・経由地・目的地・バイク仕様・往復設定が一発で復元され、即座にルートと給油所が再描画されます。
   - 不要になったルートは「🗑️」でいつでも削除可能。
2. **🔄 往復ルート設定（Round-Trip Mode）**
   - 「🔄 往復ルートにする」スイッチをONにすると、目的地が「折り返し地点」となり、出発地へ戻る周回・往復ルートを自動生成。
   - 往路・復路を合わせた全行程で給油タイミングを計算。
3. **📍 経由地の自由な設定（最大3箇所）**
   - 立ち寄りたい観光地・峠・道の駅などを経由地（Waypoints）として追加可能。
   - 地名入力（Enterで即座にピン立ち）や地図上の直接クリック、ピンのドラッグによる微調整に対応。
4. **🕒 ツーリング時刻＆営業時間判定（Opening Hours Engine）**
   - 出発時刻または帰着希望時刻を指定可能。
   - 走行時間＋ツーリング休憩（1.5時間ごとに15分加算）を考慮して、各給油ポイントの**到着予定時刻（ETA）**を算出。
   - その時間に**営業しているガソリンスタンド（24時間営業または営業時間内）**を自動選定！早朝・夜間の閉鎖リスクを防ぎます。
5. **⛽ バイク専用の給油計算ロジック**
   - `タンク容量 (L) × 実燃費 (km/L) = 理論最大航続距離`
   - `最大航続距離 × 安全率しきい値 (50%〜95% スライダー調整可能) = 給油目標インターバル`
   - 残量マージン（リザーブ容量相当の残り走行可能距離）をリアルタイム表示。
6. **📲 Googleマップ＆ナビ連携**
   - **Googleマップで開く**: 経由地および選定スタンドを順番に組み込んだ公式URLを生成。スマホで開けばそのままGoogleマップアプリで往復ナビゲーションを開始可能。
   - **URLコピー / GPXファイル出力**: LINEでの共有やバイクナビ（ツーリングサポーター、Yahoo!カーナビ、Garmin等）への取り込みに対応。

## 🚀 起動方法

### 方法1: ブラウザで直接開く（一番簡単！）
`index.html` をダブルクリックするだけで、Chrome / Edge などのブラウザでそのまま動作します。

### 方法2: ローカルサーバーで起動
`start.bat` をダブルクリックするか、ターミナルで以下を実行します：
```bash
python -m http.server 8080
```
その後、ブラウザで `http://localhost:8080` を開きます。
