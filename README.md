# MotoFuel Planner - バイクツーリング給油計画＆ルート作成アプリ

🏍️ **航続距離と実燃費から給油タイミングを自動逆算！**  
通り道にある営業中のガソリンスタンドを自動選定し、Googleマップナビへ一発連携できるバイク専用の無料WEBアプリケーションです。

---

## 🌟 主な特徴

1. **⛽ バイク専用の給油計算エンジン**
   - タンク容量(L) × 実燃費(km/L) から理論航続距離と安全マージンを自動計算。
   - ガス欠になる手前の最適なタイミングで、ルート沿いのガソリンスタンドを自動選定。
   - 「給油計画なし（ルートのみ作成）」モードも搭載し、シンプルなツーリングルート作成にも対応！

2. **🕒 通過時刻＆GS営業時間判定**
   - 出発時刻と走行ペース、ツーリング休憩（1.5時間ごとに15分）を考慮。
   - 各給油ポイントへの到着予定時刻（ETA）を算出し、その時間に**営業している実在スタンド（24時間営業や営業時間内）**を優先案内。深夜・早朝のガス欠を防ぎます。

3. **🗺️ Googleマップ公式ナビ連携（車・バイクモード固定）**
   - 出発地・経由地・給油スタンドを実際の走行順に組み込んだGoogleマップURLを自動生成。
   - スマホで開けば、Googleマップアプリでそのままナビゲーションを開始可能！
   - 下道優先（高速・有料道路回避）にもワンタップで対応。

4. **📱 スマホ完全対応＆手動スプリッター**
   - スマホ画面で地図と設定リストの比率を、指でスワイプして自由に変更可能（縦・横両対応）。
   - キーボードを開かずに地図タップだけで目的地や経由地を指定できる「ピン設置モード」搭載。

5. **📢 SNSシェア＆ルート共有（ディープリンク対応）**
   - 作成したツーリング計画を、𝕏（旧Twitter）やLINEでワンタップ共有。
   - 共有リンクを開いた仲間も、同じルートと給油計画が地図上に一発で再現されます！

6. **🏍️ 車種プリセット＆マイバイク保存**
   - 250cc、400cc、大型ツアラー、アドベンチャー、レブル、ハンターカブ等のプリセット完備。
   - 自分の愛車のカスタム設定をブラウザに永久保存可能。

---

## 🚀 使い方

1. **公開URLにアクセス**  
   https://yuito98725-prog.github.io/motofuel-planner/
2. **出発地と目的地を設定**（地図をタップ、または地名検索）
3. **愛車のバイク仕様を選択**（車種プリセットから選ぶか直接入力）
4. **「ルート＆給油計画を計算」をクリック**  
   通り道のスタンドが組み込まれたルートが完成！「Googleマップで開く」ですぐに走り出せます。

- フロントエンド: HTML5, CSS3 (Vanilla CSS, Mobile Responsive, Flex/Grid)
